yt-tools

yt-tools is a private tool that the operator uses to run their own YouTube channels. It is not offered to other users.

With the operator's permission, it uses Google APIs to:

  • upload videos and thumbnails, and schedule when they go public (YouTube Data API)
  • edit the title, description and tags of the operator's videos (YouTube Data API)
  • read view counts and other statistics of the operator's channels (YouTube Data API, YouTube Analytics API)
